🎨 Tailwind CSS คืออะไร?

แทนที่จะเขียน CSS class แยกไฟล์ คุณใส่ utility class ลงใน HTML/JSX โดยตรง — เหมือนมี CSS shorthand สำหรับทุกอย่าง

แบบเดิม (custom CSS):
/* index.css */ .card { background: rgba(255,255,255,0.07); border-radius: 24px; padding: 20px; border: 1px solid rgba(255,255,255,0.15); }
แบบ Tailwind:
{/* ใส่ class ตรงใน JSX เลย */} <div className="bg-white/7 rounded-3xl p-5 border border-white/15 backdrop-blur-xl"> ... </div>
ไม่ต้องตั้งชื่อ class consistent spacing สร้างเร็วมาก HTML verbose ขึ้น ต้อง setup build

🧩 shadcn/ui คืออะไร?

ไม่ใช่ library ธรรมดา — มันคือ collection of components ที่ copy-paste ลง project ของคุณ บน Radix UI (accessibility) + Tailwind

ติดตั้ง component เพิ่ม:
npx shadcn add button dialog select # → โค้ดไปอยู่ใน src/components/ui/ # แก้ได้ 100% เพราะเป็น code ใน project คุณ
ใช้งาน:
import { Button } from "@/components/ui/button" import { Dialog } from "@/components/ui/dialog" <Button variant="outline">บันทึก</Button> <Dialog open={open}>...</Dialog>
Accessible by default customize ได้เต็ม dark mode ใน built-in ต้องใช้ Tailwind ดึง Radix UI เข้ามา
🤔 แล้วสองอย่างนี้ทำงานด้วยกันยังไง?
Tailwind = ระบบ styling (วิธีเขียน CSS)
shadcn/ui = ตัว component (Button, Dialog, Input, etc.) ที่ใช้ Tailwind ในการ style

ใช้ด้วยกัน → คุณได้ทั้ง component library ที่สวย accessible + ระบบ styling ที่ flexible

สำหรับ My Bike: install Tailwind → ติดตั้ง shadcn → แทนที่ `.btn`, `.card`, `.modal` ด้วย shadcn components → restyle ด้วย Tailwind utilities
