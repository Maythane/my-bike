3 · Logic — brand → banner

ShockBrand table: id · name · header_image_url
User เลือก brand → shock_brand = "Profender" เก็บใน ShockSetting
Frontend init → query GET /api/shock-brands → cache brand list + image URL
แสดง banner → ถ้า user.shock_brand ตรงกับ brand ที่มี image → render ด้านบน layout
Admin: PUT /api/admin/shock-brands/{id}/image → upload PNG/JPG → เก็บใน backend/static/
